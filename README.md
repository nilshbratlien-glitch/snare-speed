# Snare Speed

Simple progressive metronome + rudiment trainer for building snare drum speed.

## Features
- Precise Web Audio metronome with lookahead scheduling
- Auto-increase tempo every N bars
- Core rudiments with real-time sticking display
- Personal best tracking (localStorage)
- Installable PWA

## Deploy
Push to GitHub and connect the repo to Netlify (no build command needed — pure static site).

## Local
Open `index.html` in a browser. For full PWA testing, serve over http(s).
